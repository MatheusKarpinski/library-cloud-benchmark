# library-cloud-benchmark
Uma API de biblioteca para avaliar arquiteturas em nuvem.

# Índice da documentação

Legenda de **status** usada em todos os documentos:

| Status | Significado |
|---|---|
| PLANEJADO | Definido no papel, ainda não construído |
| GERADO | Arquivos/código escritos, ainda não executados por você |
| VERIFICADO PARCIALMENTE | Executado em ambiente restrito (ex.: sandbox do assistente), sem substituir a execução local |
| TESTADO | Executado na sua máquina, com resultado observado e registrado |
| IMPLANTADO | Rodando no Azure, confirmado |
| MEDIDO | Existem dados brutos preservados que sustentam o resultado |
